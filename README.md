# bazi-reader 八字排盘与文化解读工具

## 项目简介
bazi-reader 是一套基于子平八字体系的结构化命理文化分析工具。以「透明推理、分层解读、明确边界，自动迭代」为核心原则，将传统八字命理转化为可溯源、可讨论的人格与周期分析框架，仅作传统文化研究与自我认知参考，不构成任何人生决策依据。

## 核心设计理念
1. **推理全透明**：所有结论标注推导依据，每一步分析可溯源，拒绝黑箱断语
2. **去绝对化表达**：统一使用「倾向、更容易、大概率」等弹性表述，摒弃宿命论
3. **分层优先级**：严格遵循「特殊格局 > 调候 > 日主旺衰 > 格局成败」的分析逻辑
4. **分歧明示**：主动呈现不同流派的观点差异，不强行统一矛盾
5. **纯工具属性**：零营销、零改运、零化解，全程无焦虑收割设计

## 功能特性
- 公历生日自动排盘：四柱干支、藏干、十神、五行分布
- 分层级命局分析：特殊格局判定、调候分析、旺衰分析、格局分析
- 十神特质解读：天赋优势与注意短板双向说明
- 大运周期概览：能量趋势参考，非具体事件预测
- 流派分歧说明：标注不同学术视角的差异与依据

## 核心优势
| 维度 | 直接扔给 DeepSeek | 八字 skill |
|------|------------------|------------|
| 排盘准确性 | 可能算错 | 脚本计算，可靠 |
| 输出稳定性 | 忽好忽差 | 格式统一，质量稳定 |
| 知识深度 | 靠模型记忆 | 有结构化知识库，利用的知识通过筛选 |
| 流派一致性 | 可能混用 | 明确体系，并且告知不同流派对于可能的分歧 |
| 安全边界 | 可能吓人，诱导消费 | 有护栏，遵循相关的法律 |
| 可复用性 | 每次重来 | 一次建立，反复使用 |
| 可迭代性 | 无法改进 | 可持续更新 |
| 可分享性 | 只能自己用 | 开源给别人用 |

## 使用说明
### 输入参数
- **必填**：公历出生年、月、日、时，性别
- **选填**：出生地点（用于真太阳时提示，不自动强制换算）

### 排盘规则
- 年柱：以立春为分界，立春前用上一年干支
- 月柱：严格以十二节气定月令，不以农历月份为准
- 时柱：默认北京时间排盘，23:00-24:00 按夜子时处理
- 说明：夜子时分界、真太阳时换算属学界争议项，结果仅供参考

### 分析流程
1. 排盘，输出四柱、藏干、十神、五行统计、大运、当前流年。
2. 看月令，取格。
3. 判断日主强弱。
4. 结合格局与强弱，定用神。
5. 看调候需求。
6. 看五行流通、十神组合。
7. 参考神煞。
8. 输出性格、事业、财运、感情等维度。
9. 看大运流年对原局的引动。

## 流派适配说明
本工具以子平正统体系为核心框架，融合三大主流视角：
- **调候派**：以《穷通宝鉴》为依据，气候优先级最高
- **旺衰派**：以《滴天髓征义》为依据，判断日主能量承载
- **格局派**：以《子平真诠》为依据，判定命局结构层次

盲派、新派等民间/近现代流派内容仅作扩展补充，不纳入核心分析逻辑。

## 边界与免责
1. 本工具仅为民俗文化研究与自我认知参考，不构成人生决策依据
2. 不替代医疗、法律、财务等专业领域的咨询建议
3. 同一时辰出生者命盘相同，但人生轨迹受家庭、教育、个人选择等多重因素影响，更多的是统计学上的意义。
4. 命理流派分歧属正常学术现象，不存在唯一标准答案
